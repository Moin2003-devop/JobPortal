# Django Job Portal

A full-stack Job Portal web application built using Django.

## Features

- User Registration & Login
- Job Listings
- Search Jobs
- Apply for Jobs
- User Dashboard
- Admin Panel
- Resume Upload
- Company Logo Upload
- Responsive UI

## Tech Stack

- Python
- Django
- HTML
- CSS
- SQLite

## Installation

```bash
git clone https://github.com/Moin2003-devop/JobPortal.git

cd JobPortal/backend

pip install django pillow

python manage.py migrate

python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
